🚌 Vadodara Bus Finder

Find scheduled buses from the supplied Vadodara timetable data.
What this version does
  • Searches the supplied timetable data by origin and destination stop.
  • Shows upcoming scheduled trips based on your device clock.
  • Shows the stop sequence used by the matching timetable.
  • Provides a Google Maps route link without requiring a Maps API key.
This is a prototype. Timetable anomalies and route/timetable mappings remain under review.
Data source: user-supplied Vadodara bus PDFs. This app is an independent citizen information prototype and is not presented as an official VMC/VITCOS service.
